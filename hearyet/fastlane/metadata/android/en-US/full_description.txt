HearYet lets a group of people listen to the same video or audio in sync, nearby — no internet, no accounts.

One device hosts a session and everyone else joins by scanning the host's QR code (or typing the code). Guests hear exactly what the host plays, in sync, and control only their own volume. The host controls what everyone hears.

Sessions run device to device over nearby connections, so nothing leaves the room. No accounts, no cloud, no tracking.

Key features:

* Host or guest, either way — start a session or join one with a quick scan
* Sync listening with a shared clock across devices
* QR code + 6-character code entry
* Local-first and private — nothing is uploaded anywhere
* Built on NextPlayer, an open-source Android media player (GPL-3.0)

HearYet is built on NextPlayer (github.com/anilbeesetti/nextplayer), an open-source Android video player.
